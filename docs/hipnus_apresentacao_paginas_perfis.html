frontend/ ├── Home.py login + redirecionamento por role ├── pages/ │ ├── 0_📊_Dashboard.py admin/super_admin │ ├── 1_🛒_Catalogo.py B2B (parceiro) ou B2C (cliente) │ ├── 2_🏪_Minha_Loja.py distribuidor/salao │ ├── 3_✉️_Convites.py distribuidor/salao │ ├── 4_📦_Estoque.py admin (central+lojas) / parceiro (propria loja) │ ├── 5_💳_Checkout.py cliente final │ ├── 6_📑_Pedidos.py admin (logistica/entrega) / parceiro / cliente │ ├── 7_💰_Financeiro.py admin / parceiro / cliente │ ├── 8_👤_Minha_Conta.py cliente: carrinho, pedidos, pagamentos, config │ └── 10_🤖_Chiara.py cliente e parceiro └── lib/ ├── auth.py JWT + require_auth(role) ├── supabase_client.py ├── session_guard.py └── queries.py

Fluxo de Acesso por Role

1. Login

  • Supabase Auth valida credenciais
  • JWT retornado com sessao

2. Resolucao de perfil

  • Busca role em public.users
  • Define menu visivel na sidebar

3. Filtro de dados

  • RLS aplica regra por linha
  • Views ja retornam dados do escopo

4. Encerramento

  • Botao Sair na sidebar
  • supabase.auth.sign_out()
